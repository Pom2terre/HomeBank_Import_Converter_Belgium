Command Line Usage:
  from scripts.services.conversion_service import ConversionService
  from pathlib import Path

  service = ConversionService()
  result = service.convert(
      file_path=Path("statement.csv"),
      converter="keytrade",
      module_name="keytrade_csv"
  )

  # Access statistics
  print(f"Transactions: {result.statistics.total_transactions}")
  print(f"Report: {result.report_path}")

  1. Launch application (.bat or Python)
  2. Add files for conversion
  3. Click "Convert All"
  4. Select a row
  5. Click "View Report" button
  6. Report opens automatically

Report Formats:
  - JSON: Machine-readable, full data structure
  - TXT: Human-readable, formatted report
  - Both formats generated automatically
  - Located beside output CSV file
  - Naming: HB_output_report.json, HB_output_report.txt
